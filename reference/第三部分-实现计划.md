### 7.3 M6 验收剧本（注意力研究流 · happy path + 失败路径）

以「注意力机制改进」为题，跑出完整链路，检验对象模型 / 复用 / 对照 / 收口 / 长跑 / import / 人机七者协同：
1. **主链路**：baseline（标准注意力）→ 多变体（改头数 / 改训练设置）→ 多 evaluation（不同评估协议 / 加指标）→ 跨变体对照下结论；
2. **import 对照 + 失败路径**：缺公认 SOTA 注意力实现 → 三闸 → `external_candidate` → license（含 **deny → 按 selection_key 换下一个 / 全拒则不物化**）→ 物化（含 **smoke 失败 → 不 `target_ready`**）→ 出厂 eval（含 **失败 → 不 `pool_publish`**）→ provenance 对照；
3. **运行日志分析 + 证据链断言**：某变体训练发散 / NaN → `execution_observation` 置「结果存疑」→ 触发复现 eval；**report 只引用复现产生的 `metric_result`、不引 log / 产物 / observation；复现失败 → 结论保持 pending / suspect**；
4. **人机 + 安全负例**：长跑中经 QQ 问「进展如何 / 继续」→ 只读应答器即时基于发布快照回话、**不改状态**；下硬 directive（如 `set_budget`）→ 门禁按时机消费、同记 DECISION；**query 误判 → 偏 directive 不自动答；directive 误判为 query → 不执行状态变更；responder 写库被 authorizer 拒**。

### 7.4 端到端研究能力测试任务（真实研究目标 · 与 §7.3 互补）

§7.3 验机制七者协同；本节给两个**真实研究目标**，验系统的**研究能力**：开放探索创新、实际刷分、真实严谨性。

**从头约束（两任务共用）。** 启动只给数据路径 + 本目标书 + 通用依赖，**禁止导入任何既有项目代码 / baseline / 结论 / 特征**——系统自建 baseline、自找并复现 SOTA、自定特征 / 范式；可读论文、不可复制其代码；外部 repo 仅作文献线索，最终实现独立并记 provenance（与 §3.6 import 准入一致）。**真实严谨性审查**经系统运行产物 + AI 执行轨迹（append-only 决策账 / evidence / `metric_result` / `execution_log`·`execution_observation` / `v_metric_result_trajectory`）+ 人工复核评估；负对照（matched-random / label-permutation / trial-randomized / confidence-only）属**任务内部 rigor**（系统应自查并入账），**不设外挂 shadow 对比任务**。数据根 `…/paper1/data/EEG_Data`（**探索可用**：SEED / SEED-IV / FACED / DEAP / MPED …；**`DREAMER` 保留为 T1 的 D 阶段 sealed holdout、不入探索池**）；算力 4×GPU、单轮 24h。

**T1（开放 · 创新）跨数据集 EEG 通用规律发现。**
- **目标**：在 SEED / SEED-IV / FACED（+DEAP / MPED 等；**DREAMER 仅作 D 阶段 sealed holdout、不入探索**）上，**范式 / 任务 / 实验全自定**，从零提出并验证**跨数据集稳健、文献未报道**的 EEG 通用特征 / 规律；找不到 → 给**可审计负结论**。
- **合格「发现」**：可复现的确定性 feature / 算子 + 它与情绪的定量 regularity；`universal` = **≥3 数据集族方向一致 + leave-one-dataset-out 仍成立**，不依赖单被试 / session / 刺激 / 预处理；门槛 = 层级 meta 分析 95%CI 不跨 0，或锁定任务上对强简单 baseline ≥2pp 且过多重检验校正。仅「attention 看着像某脑区」不算。
- **四阶段防 p-hack**：A 探索池（自由提任务 / 映射 / 假设，全 append-only）→ **B claim-lock**（冻结 feature / label 映射 / 模型 / 搜索空间 / 主指标 / 检验 / 排除规则）→ C confirmatory **LODO**（留一整个数据集只作最终 metric）→ D **sealed holdout = DREAMER**（维度标签 → 预注册 binary valence，**只评一次**；DREAMER **仅作 D 阶段**——A/B/C、HPO、预处理选择与 claim 形成一律**不得读取或试跑**）。**主 claim ≤ 3**。
- **必备 null / 控制（任务内部）**：majority / class-prior random / matched-random、label-permutation、**subject-ID / dataset-ID / trial-ID-only**（防把刺激顺序当脑规律）、source-only 线性、confidence-only、不同预处理一致性、leakage 探针。
- **novelty（验收级 novelty audit，复用 §3.2 三层查重机制、但为确认级而非 idea 粗查）**：claim-lock **后**文献查重 + query ledger；已报道同向关系 → **不算 novel**（最多复现 / 扩展），新意须落在「组合 / 跨集稳定性 / 可迁移机制 / 反例边界」并明说差异。
- **负结论形态**：「在预定义探索预算、候选空间、null 与 LODO/holdout 协议下，未发现满足 universal + novelty + robustness 的规律」+ 最强失败 claim / 原因 / 效应 CI / 下一步最小可证伪实验。

**T2（具体 · 刷分）SEED 跨被试 UDA 改进当前 SOTA。**
- **目标**：系统**从头**经文献找到并**复现**当前 SOTA，在**锁定协议**下**显著超过它**。
- **「当前 SOTA」操作定义（不写死论文）**：启动日文献检索（IEEE / arXiv / Scholar…，覆盖 `SEED cross-subject UDA` / `multi-source DA EEG`）；strict-match = SEED · 3 类 · cross-subject · target 无标签 · EEG-only · LOSO · 报全被试均值；**防挑软柿子（确定性规则）**：须纳入**近 36 月 strict-match 且声称 SOTA 的全部候选**（若 > 预注册 `N=5`，按预注册**全序**排序——发表年份新→旧、同年按声称主指标高→低、仍并列则按候选**内容哈希升序**作确定性 tie-break(合 I6 同输入→唯一规范)——取前 5）+ LibEER 风格强 baseline + 强简单 / null；保留 query ledger。**`SOTA bar = max(最强 strict 文献复现, LibEER 风格强 baseline, 强简单/null)`，必须本地复现；论文 reported 数字只作背景、绝不直接当 bar**（与 §3.6 / 第二部分 §6.9 import provenance 纪律一致）。
- **锁定可比协议**：SEED EEG-only 3 类、15 被试 LOSO（source=14 labeled，target=1 unlabeled）；主输入 1s non-overlap DE 62ch×5band；主指标 **mean-subject-accuracy** + balanced + macro-F1 + NLL/ECE + per-subject（全报）；每折独立 normalization；**target-label firewall**（训练进程拿不到 target_y，独立 evaluator 算分）+ **trial / stimulus firewall**（剥 movie / trial / 呈现顺序 ID——SEED 固定刺激极易从 trial 身份反推标签）；HPO 只用 source 内 leave-one-source-subject-out 或无监督 target-X；**同预算**（HPO trial / epoch / GPU-hour / seed）；final ≥ 3 seeds × 15 LOSO **仅在 claim / model / HPO 全冻结后一次性评估**，失败 seed 计入；**final target 指标不得回流 HPO / 模型选择 / 下一轮改法**（独立 evaluator 出分，防多轮窥探 target 分数的间接泄漏）。与 gate_input 隔离（第二部分 §6.13(2)）**同纪律**（任务级类比，非同机制）。
- **必过简单 null（promotion bar 一部分，非附录）**：majority / source-prior random、source-only 线性 / MLP / deep、单最佳 source、confidence-only 伪标签、label-shuffle / trial-ID-only 泄漏探针。
- **晋级判据**：先过复现关（≥ 1 strict SOTA 在锁定协议下复现成功或给可审计失败因）→ 主指标 **≥ 1.0pp 且 paired bootstrap 95%CI 下界 > 0 且 Holm 校正显著** → **≥ 10/15 被试不劣** → 3-seed 均值为正、最差 seed 不低于 bar 超 0.5pp → **ablation 解释主要增益 ≥ 一半**。否则结论 = **「不达 SOTA / 改进无效」**，不得拿次指标或非严格协议包装成功。

**收口（两任务，I3）。** 任何结论须经 §3.5 reasoning 收口、回溯到一次成功的 `metric_result`；**训练 / 评估轨迹与观测只作审计 / 解释 / 存疑过滤，永不作正向关问 evidence、不进 metric_result**（I3，§3.1.2 / §1.4.3）；全 subject / seed / fold / dataset **append-only 全量报告**，失败是报告对象。
