# 研究内容表面职责

发现、正文读取、执行输入和阶段上下文各有职责；同一原件通过准确引用复用。具体工具合同与优化范围见[实施规格 #262](https://github.com/15253a/meta_research/issues/262)及对应实现票。

| 表面 | 职责 | 边界 |
| --- | --- | --- |
| `research_notes` | 跨阶段交接说明的发现与正文读取 | 不承担执行输入绑定或 Plan 依据目录 |
| `plan_evidence` | Plan 已选依据的目录与精确正文 | 不承担执行输入；依据不按材料类型设资格 |
| `reasoning_evidence` | Reasoning 冻结证据闭包的只读上下文 | 不承担研究发现或接纳新内容 |
| `implementation_content` | Bundle 侧实现内容的接纳与执行输入绑定 | 不承担研究说明或依据目录 |

服务器资料递交见[工作资料引用合同](server-work-materials.md)。近期工作目录的原生访问由 #262 的对应实现票接通；它与服务器资料递交分别核对，不在本文复制工具清单或实现状态。
