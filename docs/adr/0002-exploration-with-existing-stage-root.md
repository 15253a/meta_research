# 在现有阶段根会话中承接 Exploration

2026-09-10，用户选择以现有 Bundle 阶段承接 Exploration：阶段根 Session 直接负责分析与探索，需要实验时使用既有 Target，不再增加另一类探究对象与根 Session。每个 Cycle 仍绑定一个 Question，保持阶段单向推进与 Reasoning 的整轮复盘；一次探索允许没有显著收获。

用户进一步明确最小循环为“猜、计划、做、总结”：Idea 负责猜与头脑风暴；Plan 负责计划，并必须保留既有历史索引能力；Exploration 负责实际研究，实验使用 Target；Reasoning 负责整轮总结。简化交接合同不得削弱 Plan 查找与利用既有研究历史的能力，也不得把所有研究活动预先限定为测量实验。

该选择复用现有阶段与执行基础，避免为一般分析再建立一套对象生命周期。交接合同只保留必要边界，并在 context_pack 中保留来自上游 Session 的自由语义备注；研究方法和叙述不应普遍套用测量实验合同。具体最小字段、Plan 与 Exploration 的调整边界、备注承接规则仍待讨论。此文记录设计方向，运行时尚未实施改名、schema 变更或新完成路径；ADR 0001 的单向阶段约定继续有效。
