# 六大入口组织研究进展、过程方法与可复用资源

2026-09-24，用户确认 Environment 作为第六个研究索引入口，覆盖研究交互／仿真环境、可复用计算运行环境，以及实验者已有的设备、设施、场地和其他现实物理资源。环境和数据集往往构建或取得成本高且被反复采用，需要让后续研究直接找到已有积累。Environment 可以是已有或外部资源，也可由 Target 沿既有 Baseline → Variant → VariantRun 层级构建并保存；增加入口不改变该执行和存储逻辑，也不新增并行的环境构建生命周期。

用户进一步明确六入口的不同侧重点：

| 入口 | 主要复用或查看目的 |
| --- | --- |
| Question | 研究进展总览：问题关系、做过的工作、当前认识、未解决事项与后续方向 |
| Baseline | 方法与过程复用：沿方法、变体及真实实施查看具体 Target 工作、输入和结果 |
| HumanRequest／人类输入 | 人类协作过程与经验复用：请求、尝试、答复、主动指导和采用背景 |
| Literature | 文献及有价值阅读认识的复用 |
| Dataset | 已有或研究中产生的数据资源复用 |
| Environment | 虚拟环境、现成设备设施及现实研究资源复用 |

这是入口的侧重点，不是互斥的资产分类。Question 本身仍表达研究问题，其入口提供类似研究进度报表的总览；Target 的实施记录继续从 Baseline 体系展开。HumanRequest 保留人类协作过程，同一入口也保留既有的主动人类输入。各入口关联真实来源和已有内容，不要求为检索复制原件。

这里用户所说的“索引快照”表达便于发现和采用的含义概览及引用。数字材料沿既有精确内容版本读取；实体资源通过其身份、位置、能力和已知条件等信息被识别，相关说明或记录可保存在 RM 中。说明文件的内容 hash 只标识该文件，不表示物理设备或场地本身被冻结或已核验。已有 GPU／算力设备本身可以是 Environment，某 Quest 的本次选卡与预算配置继续表达本轮工作条件。

对 Target 新产生的 Dataset 和 Environment，用户选择在相同的入库整理和核验环节处理：对已保存成果识别复用价值、登记适当入口，并关联原研究工作及内容引用。已有设备、设施和其他现实资源可按真实来源直接登记，不要求补造构建 Target 或等待一项新研究完成。沿用已有的身份、来源和数字内容接纳能力，不因新增 Environment 建立额外审计或批准流程；本决定不要求一次数据库事务，也不改变此前暂缓未完成 Target 产物中途发布与提前消费的范围。

现成环境可以按已有持久目录、安装状态或服务及其使用说明直接登记，不要求先完成跨机器打包或完整重建配方。用户明确：在其他机器上使用时需要的适配或修复属于新 Target 的工作，不影响原模拟器的入库资格。新 Target 沿既有 Baseline 层级保留其实际工作和结果，关联原环境作为来源；若实际内容改变，继续沿已有精确内容与版本原则处理，索引归类粒度仍由 Agent 判断。

本记录扩展 [ADR 0005](0005-research-assets-and-shared-content.md) 的五入口为六入口，其余方法层级、RG／RM 分工、Agent 自主归类及共用内容原则保留。本轮范围和职责边界已确认；此决定不表示 Environment 已实现或部署。
