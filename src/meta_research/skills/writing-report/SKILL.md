# 研究写作

这是一份共用写作 Skill。执行本次任务的助手或研究 Agent 直接使用它，按请求完成提纲、初稿、局部修改或正式成品。Skill 提供写作原则与文体指导；会话、工具、工作目录、资料权限和保存方式沿调用方已有环境。

## 任务与材料

保留用户或调用方的完整要求，明确本次要写什么、给谁看、用途、语言、研究范围、模板与输出形式。仅加载本次所需的[论文指导](references/paper-v1-advisory.md)、[报告指导](references/report-writing.md)或[演示指导](references/presentation-v1-advisory.md)。局部写作按本次任务完成；未明确要求切换语言时沿用所选前稿的语言、风格与格式，修改范围外的内容保持不变。正式交付按成品要求完成。

结合直接提供的关键结论、结果、反证和限制理解研究，再按论证需要阅读准确原件及历史。材料入口和摘要帮助定位，重要主张、数字与引文以实际读取的来源为依据。保留影响判断的负结果、失败、缺测与适用条件。

模板规定结构、样式与文件形式；模板示例中的作者、数字和引用不作为本研究事实。使用模板前检查原件及必要依赖，缺少非关键偏好时采用适合用途的默认值。

取材前读取[任务上下文与交接](references/context-and-handoff.md)，按调用入口处理开始时的研究基准、准确版本与成果交接。

## 写作原则

**拒绝防御性写作，适用于论文、报告与 PPT，也适用于 Cycle 内写作。** 对有依据的发现、贡献和判断直接陈述，用具体事实与论证支撑表达。去掉反复免责、无具体依据的模糊措辞、自我贬低和系统审核口吻。必要的适用条件、统计不确定性及局限应具体说明其科学影响，放在相关结果、方法或讨论中，保持结论强度与证据一致。

论文从已有证据抽象出问题、缺口、方法、发现与贡献之间的故事；报告严谨说明怎样做、实际结果及其含义。PPT 配论文突出故事和论证，配报告突出方法、结果与实际情况。段落、章节和幻灯片为读者理解服务，研究执行顺序只在解释方法或结果确有需要时出现。

正式正文只包含研究内容。关键主张与图表到来源、版本、位置及计算方法的关系保留在内部工作材料中；正文使用正常的参考文献、图注和必要方法说明。工具日志、调度记录、审阅处置与系统审核标签留在会话记录中。

允许忠实转述、翻译、多来源综合与透明的派生分析；逐字核对用于直接引文。按[科学表达与证据](references/scientific-writing.md)核对含义、范围与支持关系。改善图表选择、配色、布局、标注和有效数字，保持原始数值及实验事实真实；派生数值由工具实际计算，留下输入与方法。

## 审校与交付质量

按任务范围检查论证、引用、数字、图表和文体。正式成品安排独立审阅，提供完整稿件、相关依据和准确原件；执行助手核实意见并修订。独立审阅服务于质量，不成为新的审批角色，也不要求每次提纲或局部修改重复完整成品流程。

审阅时改写没有科学信息的免责句和重复弱化措辞，保留影响读者判断的具体限定。多种成品共享事实时，核对数字、术语、图表含义和结论范围一致。

以本次请求判断完成。只要提纲或初稿，就交相应内容；要求正式文件时，按模板制作并查看实际页面或幻灯片。论文优先可编译 LaTeX 工程与 PDF；报告按要求交 DOCX/PDF 等；配套 PPT 交可编辑 PPTX。用户指定形式优先，实际可用的制作工具按需调用。

交付正式文件时保留所需源文件、图表、书目与依赖，确认可打开、可继续修改且版面清楚。外部模型生成的文字同样需要核对、编辑与排版；返回文字不等于正式文件已经生成。简短交付说明给出文件及实质性缺项，保持正文为纯粹的研究表达。
