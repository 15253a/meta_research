# 任务上下文与交接

Writing Skill 由普通助手或研究 Agent 在其任务中使用。本文件只说明写作所需的信息与结果归属；普通会话的创建、恢复、工具权限和文件保管沿平台既有职责。入口与旧实现的调整见[已定 Writing 设计](https://github.com/15253a/meta_research/issues/259#issuecomment-6470600076)。

## 调用方提供什么

直接提供完整要求、输出类型和阶段、受众与用途、语言、选定研究范围、模板和输出位置。与本稿相关的关键结论、结果、反证和限制直接给；完整历史及来源保留准确、可读的入口，按需展开。模板给原件与依赖；修订任务给准确稿件、可编辑源和反馈原文。

按写作要求从全部获授权研究材料中自主取材，沿研究目录查找相关问题、计划、实验、数据、环境、研究结论、文献和人类输入，再按论点读取原件。用户手选材料用于指定前稿、模板或重点来源；未手选也照常开展取材，页面和首包只是起点。按需查找，实际采用的材料保留准确版本与来源。

人类独立写作以首包 `scientific_context.basis_observed_at` 和所附准确来源为开始时的研究基准。后续查到材料时，优先沿已有历史、版本和接纳时间取得基准时已存在且与本稿相关的版本；当前目录或最新版本仅是发现入口，不证明它属于开始时状态。已有准确来源继续使用原版本。历史版本不可读、时间无法确定或只能取得后来资料时，说明缺项及实际采用范围，先交已有证据支持的稿件；后来资料如作为补充使用，要标明其时间及对结论的影响。始终核验当前读取授权。

长期写作或后续修改沿原基准、准确材料和稿件版本续接；人要求更新资料时，明确采用的新材料及其对稿件的影响。研究任务内写作沿调用者本次任务的材料与采用关系，不额外施加独立助手的开始时间。实时未完成日志如需引用，应保持其观察状态，不当作完成实验。版本读取和保存复用已有工具；开始基准不表示整项研究的所有资料都已冻结。

## 完成责任与操作边界

**人类独立发起：** Writing 界面把设置交给普通助手的新会话。助手完成现有证据能支撑的版本，实验建议另列交人，必要科学条件留在正式正文。写作交付到人为止；不等待补实验，不主动提交研究指导、创建实验任务、修改 Cycle focus 或向研究流程派工。

**研究任务内使用：** 研究 Agent 在已有任务中直接调用同一 Skill，按任务需要分工。提纲、初稿、修订或写作发现的问题返回原调用方。是否补实验、怎样安排后续研究，仍由该研究任务的现有职责决定。使用 Skill 本身既不创建人类独立会话，也不改变研究权限。

独立入口和研究任务都可以制作正式文件，也都可以仅完成请求的草稿或局部工作。完成程度取决于本次要求，不取决于调用入口。

## 模型、产物与后续修改

人类独立入口默认由当前 Codex 助手写作。人选用自带 API 时，同一助手依据传入的地址、模型、协议和调用说明取得模型内容，再核对、修订和生成文件；任务携带凭据引用，实际凭据由普通会话可用的环境或配置提供。模型调用错误如实返回给人，不悄悄换成另一模型后声称按指定模型完成。

外部内容通过 `assistant.content.generate` 调用；按当前用途目录发现操作并取得合同。界面 Writing 的模型选择已绑定普通会话，调用只传本次需要的 `messages:[{role,content}]`，同根修订沿原选择继续。研究内调用提供已选 `config_ref`，或任务的 `model` 对象（`kind:task_api`、完整 `endpoint`、`model` 名、`protocol`、`api_key_ref` 与可选 `instructions`）。支持 `openai_chat_completions`、`openai_responses`、`anthropic_messages` 三种非流式文本协议；调用说明是非秘密内容要求，不是任意 HTTP 参数、代码或新协议。密钥通过界面独立保存或受限环境引用提供，不能读取密钥文件、在原生 shell 重建请求或把密钥放进消息与文件。主文和修订内容均由所选内容模型承担，助手保留核对、排版和文件制作职责。

失败读取工具的 `details.reason_code` 和 `correction`：凭据或权限拒绝需要修正凭据/授权；限流要先查额度或等待条件；服务故障查服务；超时或结果未知先查服务记录和已有产物，不盲重试；协议不符、拒绝或不完整正文不能当作成功稿件。保留原稿、准确材料、任务和模型选择，简短向用户说明实际影响及下一步。界面的“保存密钥”可更新原引用后继续同根任务；更改模型属于人的新选择，不自行代换。配置缺失不表示材料错误，也不要求用户重填所有写作要求。

使用用户所选模型时只传写作需要的相关要求、稿件、模板说明和来源。普通助手仍负责工具调用、准确事实与文件交付；外部 API 的文本回复不代表来源已核对或文件已生成。

文件保存在普通会话可持续访问的输出位置；多份稿件各有明确版本和依赖。修订继续使用准确前稿，保留已有交付版本。交付给用户与投稿、公开发布或发送第三方分别按实际授权执行。科研来源关系和需长期保存的研究产物继续使用现有材料保管能力。
