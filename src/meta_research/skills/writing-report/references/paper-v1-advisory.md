# 论文写作：paper

在本次助手或研究任务中按主 Skill 写作原则处理论文；局部写作使用相关指导，完整成品使用下列交付要求。章节和格式由实际文章类型与用户模板决定。

## 读者、故事与贡献

先确认论文类型、目标读者或投稿场景、研究材料范围、用户/期刊模板及语言。按实际类型选择结构：实证、方法、理论和综述可以有不同的论证顺序；模板确有规定时遵守，而不是把同一 IMRaD 或固定章节数套给所有论文。

从已有材料回答：研究针对什么问题，为什么现有知识不足，本研究做了什么，哪些结果回答了问题，这些发现增加了什么认识。把答案组织为一条证据支持的主线。章节顺序服务于读者理解，实验执行顺序仅在方法解释所需处出现。

贡献要具体，说明适用范围和与已有工作的关系。创新性断言须由实际文献与结果支撑。已有证据只支持限定结论时，把它写成明确、有效的贡献；不靠夸大、虚构实验或遮掉相反结果制造故事。

配套 PPT 以同一问题、贡献与关键证据组织故事，帮助检验稿件主线，按 [演示指导](presentation-v1-advisory.md) 调整视觉与口头表达。

## 写作与图表

依 [科学表达与证据](scientific-writing.md) 写完整段落及正常引文。摘要让读者理解问题、方法、主要结果和意义，量化描述来自真实结果；摘要、正文和结论使用一致的范围。引言建立问题与缺口，相关工作比较实质差异，方法使核心处理可复核，结果围绕科学问题呈现，讨论解释发现及其边界。

把关键图表当作论证组成部分：每张图回答明确问题，正文解释其意义，图注说明条件、样本、单位、误差或其他必要定义。主要发现优先使用能让人判断效果和差异的表达；完整补充结果放在适当附录，而非删除。公式、符号和术语全文一致。

局限按科学需要放在方法、结果或讨论中，通常集中说明重要适用条件、替代解释和未解决问题。措辞直接而准确：事实陈述不无故反复自我怀疑，解释不冒充已证实因果。正文不放审核标签、内部证据 ID 或写作过程说明。

## 模板、LaTeX 与交付

优先使用用户或目标期刊的 LaTeX 模板。检查主文件、class/style、bibliography、图表格式及字体依赖，保留其真实样式和结构要求。没有模板时采用适合论文类型的简洁 LaTeX 工程。用户要求 DOCX 或指定其他模板时按其要求交付。

完整论文交付包含可编译源文件、真实书目记录、所用图表和 PDF。图表生成脚本/数据按需要一并提供；引用采用模板要求的正常书目样式。源工程中的文件路径可移植，编译不依赖未交付的临时目录。作者、单位、资助、日期、声明和伦理信息仅来自真实输入；缺失的必要项目如实标为待补，不编造。

实际编译并查看 PDF 页面，核对公式、交叉引用、书目、表格、图注、分页及字符显示。修复编译失败、缺图、未解析引文、溢出或裁切后重新查看相关页面。成功生成 PDF 仍需确认内容与审阅后稿件一致。

完成条件：形成证据支撑的完整论文，独立审阅和修订完成；用户模板得到尊重；PDF 可阅读，LaTeX 或用户指定可编辑源及依赖可复用。交给用户的论文不等于自动向期刊投稿，外部提交沿实际授权执行。
