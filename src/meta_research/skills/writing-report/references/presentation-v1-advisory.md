# 演示文稿写作：presentation

在本次助手或研究任务中按主 Skill 写作原则处理 PPT；局部写作使用相关指导，完整成品使用下列交付要求。页数、版式与讲述结构由实际用途和用户模板决定。

## 配套文稿与表达重心

先确定听众、用途、演讲时长或所需篇幅、语言、所依据的论文/报告版本与用户模板。PPT 与配套文稿共享研究事实、术语、图表含义及结论范围，按交流目的安排讲述。

| 配合对象 | 表达重点 |
| --- | --- |
| 论文或稿件 | 以故事性和论证为主，串起问题、动机、贡献、关键证据、发现及意义；PPT 帮助听众抓住主线，稿件承载完整论证。 |
| 研究报告 | 以真实性和准确说明为主，交代目的、条件、怎样做、实际结果及适用范围；关键设置、负面结果和未完成项按其研究意义呈现。 |

两种配合都以真实事实和科学支持为基础。故事性体现在组织、重点与衔接，原始数字、实验事实和结论范围保持准确；真实性也需要清楚的讲述，不等于粘贴过程流水。配合关系指导表达，不新增固定任务类型或审批流程。

按听众需求重新组织内容，不逐页粘贴文稿段落。页数由时长、内容和模板决定；细方法、完整结果和补充引用可放在备份页或讲稿。人类独立交付发现的额外实验建议按 [操作边界](context-and-handoff.md#完成责任与操作边界) 单独交给人，必要的研究局限仍在对应页中说明。

## 每页承担一个主要目的

标题表达本页关键发现或问题，图表、示意和简洁文字共同说明它。优先让听众看清研究对象、比较关系和数据含义；保留必要单位、图例、样本、尺度与不确定性。概念示意与实测结果以清楚图注区分。

简化文字时保持原论证范围。重要限定若影响听众判断，放在本页合适位置，不能只藏到讲稿；完整说明和正常书目可以放入讲稿/备份页。正文不带 Inference 等审核标签，也不暴露内部来源版本、工具日志或运行过程。

已有论文或报告图可以复用或针对演示重新绘制，数字与结论保持一致。图表美化、聚合或派生分析沿 [科学表达与证据](scientific-writing.md) 执行；图表不能因视觉效果更好而改变实验事实。

## 模板、可编辑性与交付

读取用户 PPTX/POTX 等模板的母版、布局、字体、主题色、比例及页码/品牌要求；采用其可用布局，移除与本研究无关的样例内容。模板是表达资源，其样例数据和参考文献不自动成为证据。没有模板时使用适合场景的简洁版式。

交付可编辑 PPTX：标题、正文和布局使用可编辑对象，适合的数据图保留编辑所需数据或生成源；科研图像可作为图像对象，并提供必要原图。不要把整套内容扁平化为一组截图后称为可编辑演示稿。按用户要求附 PDF、讲稿或图表源文件。

实际渲染每页检查标题/正文/图表的层次、密度、对齐、裁切、字体和对比度，并核对常用演示比例和可读性。可编辑性、内容一致性和视觉质量分别检查；文件生成成功不等于演示质量合格。

完成条件：讲述顺序适合听众和时长，表达重点符合配套稿件或报告的用途，与所依据版本事实一致，逐页图文清楚；模板已应用，PPTX 可打开且主要内容可编辑，必要补充材料齐备并已视觉检查。
