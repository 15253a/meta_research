# 科学表达与证据

三种文体共用的目标是准确、清楚、有解释力的研究表达。具体结构由论文、报告或 PPT 的用途决定；正文质量与内部追溯分工见 [上下文与交接](context-and-handoff.md)。

## 从证据形成论证

先找出用户所选研究中可以回答的问题、实际采用的方法、最有解释力的发现及其意义，再据此组织材料。论文中的故事是这些要素之间有依据的联系，不是按实验发生顺序重述记录，也不是预设一个结论后挑选材料。结果章节围绕发现及其证据推进；对照、分析和图表说明为什么能作出该判断。相关写法参考 [Nature/Science 风格指导](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/venue-templates/references/nature_science_style.md)，并按实际学科和文章类型调整。

贡献要能指明新增认识、方法或证据及适用范围。文献缺口、首次/最优等断言需要真实依据；若证据不足，选择能成立的贡献表述。对结论有影响的反例、无效结果或替代解释一并进入判断，在正文或合适补充材料中交代其科学意义。

报告重在清楚说明方法和结果；PPT 则把同一事实重组为可讲述的视觉论证。三者的差异是本项目依据用户需求作出的设计，不是外部技能规定的统一结构。

## 拒绝防御性写作：直接、精确的科学语言

使用具体主语、清楚动词和有内容的段落。每段推进一个科学论点，连接证据及解释；段落之间形成可理解的推理顺序。方法说明实际做过的事情，结果写实际观察或计算到的结果，讨论解释意义并界定范围。数字、单位、符号、术语及方法在全文保持一致。参考 [Scientific writing principles](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/scientific-writing/references/writing_principles.md)。

主张强度由研究设计和证据决定。对明确观察直接陈述；相关性、机制解释和推测使用与证据相称的动词。限定应说明具体条件或影响，而不是反复出现“可能不准确”“仅供参考”一类免责句。学科确需的不确定性、置信区间与局限属于科学内容；系统的 Inference、审核状态和模型自评标签不属于正文。

逐段落实主 Skill 的要求：先写清本段的发现或判断，再给依据和必要条件。删除不增加科学信息的免责声明、自我贬低和重复退让；“可能”“提示”等词只在研究设计或证据强度需要时使用，并对应具体含义。能用准确条件表达的范围，就直接写出条件，避免用泛泛的谨慎口吻削弱已成立的结果。

把影响特定结果的条件放在该结果附近，把较广的适用范围和未解问题放入讨论或方法。可以集中说明重要局限，不为完成形式清单制造泛泛的局限章节。结论不引入未经结果支持的新事实，摘要与正文保持同一口径。

## 引用与支持关系

正文允许忠实转述、翻译和跨来源综合，使用模板/学科要求的普通文内引用、脚注和参考文献。书目作者、题名、年份、DOI/URL 等来自实际来源，不凭记忆补造。引用放在所支持的主张附近，既不把引文当作装饰，也不把所有句子写成直接摘录。

内部证据映射服务于根和独立审阅的核对，连接重要主张或图表、精确来源版本及定位、支持关系、适用范围/边界，必要时加原文片段和计算依据。按可核查的论点组织即可，不需要每个句子或转折词一条记录。它沿既有来源与保管职责保存，默认在工作区；需要时可单独提供给用户，不能自动并入正式正文。

| 内容类型 | 核对责任 |
| --- | --- |
| 直接引文 | 原文逐字、来源身份及精确位置；正文清楚呈现为引文 |
| 转述或翻译 | 原意、适用条件、断言强度和真实引用；不要求与原文字符串相同 |
| 多来源综合 | 各来源的相关性、可比性及共同支持的范围，组合后的结论未超出证据 |
| 派生分析 | 真实输入、可追溯方法/参数、实际计算和合理解释 |
| 关键科学主张 | 根读取证据并作判断，独立审阅核对完整稿、相关映射和必要原文 |

这些规则替代旧的“supported 全块等于 source_quote”写作合同。工具可以检查来源存在、引文定位、数值运算和文件结构；科学支持不由字符串相等或新增审批角色代替判断。

## 数据、图表与适度美化

美化应提升准确理解：清晰标题、适合问题的图形、可读配色与排版、正确单位、合理有效数字、一致符号、真实比例及清楚图注。统计摘要、聚合、归一化或其他派生分析可以增强解释力，但须实际执行计算，保留输入、方法、处理和对结果有影响的选择；表格和图中的数值与计算产物一致。

原始测量、样本、实验条件、比较对象、误差和统计结果保持真实。不得填造未做的实验、补造显著性、修改数值或选择性隐去足以改变结论的不利结果。舍入、坐标截断、对数变换或筛选若会影响读者理解，应在合适位置说明；不借误差条或坐标视觉制造未获得的证据。

概念/示意结构图与实测/派生结果图在图注中可辨。派生汇总图说明口径、输入和来源；坐标、误差与颜色的意义对应真实内容。图表既有独立可读的标题/图注，也与正文主张对应。PPT 的视觉简化保留必要科学条件；相关原则也见 [Scientific slides 指南](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/docs/skill-guides/scientific-slides.md)。
