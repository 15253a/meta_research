# Owner operations

Research Graph owns Target identity, immutable TargetSpec, DAG edges, frontier,
Target-to-TargetRun binding, and TargetCommit. Propose values; never assert that
RG accepted them.

Agent Runtime owns Bundle StageRun, technical Attempt, root/native Session,
Fence, formal micro-experiment TargetRun, provider effects, logs, and execution
receipts. A short Harness child Agent is not a formal TargetRun.

Research Memory owns immutable code, definition/protocol, checkpoint, log,
analysis, and result AssetVersions. Reference accepted bindings; do not infer
acceptance from a path or generated bytes.

Advancement Engine owns Bundle eligibility, exact StageRunRequest, skipped or
completed disposition, and StageCommit. Execution completion and TargetCommit
do not advance the Stage by themselves.

Human Collaboration owns high-risk authorization and reconciliation requiring
human judgment. Normal targets may be scheduled automatically under the Quest's
accepted broad authorization. Never manufacture an authorization from chat.

A TargetCommit must close the executed implementation, definition/protocol,
input bindings, checkpoints, MetricResult, execution receipt, logs, and analysis
for one exact TargetRun. Preserve already committed sibling targets when another
target is blocked or fails.
