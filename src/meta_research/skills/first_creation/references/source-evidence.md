# Source evidence

The manifest names captured workspace files, byte counts, hashes, and external origins. Read sources through native filesystem tools. For each observed range return material_key, offset, length, chunk_sha256, and an actual section or line description in location. The Owner checks the bytes. Do not report a range you did not read.

Coverage includes every manifest source. Use read only when ranges cover all bytes. Use partial with exact observed ranges and an unread_description. Use unread with no ranges and a truthful entrance description. Claims about content need observed sources. Composition, gaps, and unfinished questions can describe an entrance or a missing source without claiming its content. Conditions stay beside the claim they qualify.

Selection records contain material_key and a reason for custody. Selection does not manufacture research execution. Original producers, external folder paths, and imported results remain external origins. Unselected sources stay available through captured workspace entrances and may later report changed or unavailable bytes.
