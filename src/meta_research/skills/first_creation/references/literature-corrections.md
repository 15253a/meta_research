A requested DeepFetch route still performs the focused new search. Explain the change. `original_sources` contains material keys from the original basis. `literature_sources` contains the actual `paper_id` and `locator` present in the accepted literature. Preserve all six understanding fields, source entrances, coverage, and the exact material selection, including custody. Preserve the distinction between reported work and inference. Keep conditions with their claims. Adjust conflicts, gaps, and unfinished questions when evidence warrants it. Do not invent a correction for an honest empty result.

New claims about server materials cite only the `read_witness` returned by MCP reads during the current protected operation. An ordinary scoped Reader RM page does not create an MCP witness. Previous sessions and ordinary Reader browsing do not count as this operation's input consumption. Legacy captured sources retain their checked byte-range citations.

Later literature changes use the complete revision schema and keep earlier applicability, inherited evidence and exact selected versions.
